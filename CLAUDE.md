# Kyiv Badminton Olimp — project instructions

@OLIMP-DESIGN-SYSTEM.md

## Design rules

* Перед созданием или изменением любого пользовательского экрана, компонента, секции, карточки, кнопки, текста, изображения или анимации обязательно руководствуйся импортированной дизайн-системой.
* `OLIMP-DESIGN-SYSTEM.md` является главным источником правил по цветам, типографике, сетке, отступам, карточкам, кнопкам, изображениям, видео, анимациям и адаптивности.
* Не создавай новые визуальные стили, цвета, шрифты, размеры, радиусы, тени или принципы анимации, если задача может быть решена средствами существующей дизайн-системы.
* Если запрос пользователя намеренно меняет дизайн-систему, сначала реализуй согласованное изменение, а затем обнови `OLIMP-DESIGN-SYSTEM.md`, чтобы документ соответствовал фактическому сайту.
* Не изменяй уже утверждённые секции, если пользователь прямо не попросил их изменить.
* При работе только над одной секцией не затрагивай остальные части сайта.

## Language

* Все тексты, видимые посетителю сайта, должны быть на украинском языке.
* Русский язык в пользовательском интерфейсе запрещён.
* Допускаются только короткие английские фразы как декоративные элементы.
* Технические отчёты пользователю можно писать на русском языке.

## Responsive checks

После каждого визуального изменения проверяй сайт на ширинах:

* 1440 px;
* 768 px;
* 375 px.

Обязательно проверяй:

* отсутствие горизонтальной прокрутки;
* читаемость текста;
* отсутствие перекрытий;
* мобильную навигацию;
* правильную работу анимаций;
* `prefers-reduced-motion`;
* отсутствие ошибок в консоли.

## Project materials

* Не изменяй и не удаляй исходные файлы в папке `site-materials`.
* Не придумывай отсутствующие ссылки, адреса, отзывы или контактные данные.
* Не используй визуальные референсы как готовые изображения сайта, если они обозначены только как референсы.

## Git

* Не создавай коммит без отдельной команды пользователя.
* Не выполняй push без отдельной команды пользователя.
